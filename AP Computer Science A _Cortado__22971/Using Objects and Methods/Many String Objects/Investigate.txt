Question 4: How does reassigning a string variable
affect the original object it was pointing to?


Reassigning a variable does not change or destroy the original object. It only changes which object that specific variable is currently referencing. If no other variables are pointing to the original object (like "Hello"), it becomes "unreachable," and Java's Garbage Collector will eventually remove it from memory to save space. Strings are immutable, meaning the objects themselves cannot be changed once created; you can only change which object a variable points to.
