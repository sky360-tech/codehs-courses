1. The enhanced for loop is easier to read — for (int item : arr) basically reads as "for each item in arr", and you don't have to think about the index at all. Less mental overhead.
2. No, you wouldn't need to change either loop. The traditional loop uses arr.length so it automatically adjusts, and the enhanced loop just iterates over whatever elements exist. Neither has a hardcoded size.
3 (Modify) + 4. You can only use the traditional for loop in doubleValues. The enhanced for loop gives you a copy of each element in a temporary variable (item), so writing item = item * 2 would just change that local copy — the actual array stays untouched. The traditional loop gives you direct index access (arr[i]), so arr[i] = arr[i] * 2 actually modifies the array itself. The print methods can use either loop because they're only reading values, not writing back to the array.
