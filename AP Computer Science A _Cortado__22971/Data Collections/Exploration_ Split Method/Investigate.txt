4. What is the for loop doing?
It loops through every word in arrayLine (the split-up version of one line). For each word, it checks if it matches the target word. If it does, the counter goes up by 1. It's basically scanning every single word in the line one at a time.

Modify — count changes with .toLowerCase():
Before adding .toLowerCase(), words like "Shake" at the start of a line wouldn't be counted since it doesn't exactly match "shake". After adding it, those get caught too, so the shake count goes up. Same idea for you — any capitalized version like "You" would've been missed before.
